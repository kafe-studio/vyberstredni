# Vyber střední

Webová aplikace, která pomáhá žákům 8.–9. tříd a jejich rodičům vybrat střední školu podle zájmů, náročnosti přijímaček, obsazenosti, školného a dojezdu. První verze pokrývá Prahu a Středočeský kraj.

Postaveno na šabloně [kostra](https://github.com/kafe-studio/kostra) (Astro + Cloudflare Workers).
